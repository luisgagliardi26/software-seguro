# Objetivo 1 - Mapeo Lógico

Consigna: Selecciona una de las aplicaciones web de prueba de Software Seguro (o un sitio web tradicional). Elabora un diagrama de flujo simple (puedes usar herramientas gratuitas como draw.io o Excalidraw) que ilustra paso a paso cómo viaja un dato desde que el usuario interactúa con la interfaz web (Frontend), pasa por el procesamiento del servidor (Backend) y termina interactuando con la Base de Datos. Identifique claramente en qué tramo exacto de este viaje ocurre la protección del protocolo HTTPS.
